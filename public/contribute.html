Help find lost ships

Point your computer at a stretch of seabed nobody has searched. Claude Code runs the hunt and sends what it finds to the shared map. The first area re-found 72 of 80 charted wrecks with no hints.

Open the code on GitHub
1Pick a coast with public sonar
2Download the seabed map
3Find every ship-sized bump
4Prove it on known wrecks
5Check the best ones by eye
6Pull request, then it's on this map
1

Get the code

Mac or Linux, Python 3.12, Node 20. 1 to 10 GB of free disk, no GPU.

git clone https://github.com/royherma/wreck-hunt && cd wreck-hunt python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
2

Start a hunt

Open the folder in Claude Code and name a place. It reads the guide in the repo, says how big the download is, then works through the 13 steps.

/hunt Bunurong Marine Park, Victoria, Australia

Codex or another agent: "Follow CLAUDE.md and run a hunt on <place>". No agent: the same steps are in the README.

3

It opens a pull request

Only the results go up: the best 200 close-ups, the scores, the recall test, and new finds placed in a 20 km square. Once merged, the area shows up in the area menu here.

node scripts/package-area.mjs <area> && gh pr create
